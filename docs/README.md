# Documentation

Guides for the AI SDLC Framework's development workflow, with integration
support for **GitHub** and **Azure DevOps**, including **GitHub Actions** and
**Azure Pipelines**. Start with the task you want to accomplish.

These guides explain the supported capability scopes and host prerequisites,
and distinguish released behavior from candidate work.
See [integration support and pipelines](integrations/README.md).

## Internal development records

[Canonical SDLC records](sdlc/README.md) preserve requirement/test IDs, approved
snapshots and historical evidence references. They are implementation records,
not reader tutorials, current approval decisions or evidence that this candidate
passed. Generated execution reports belong to declared evidence retention, not
reader topics; raw operational/session logs are not published here.
