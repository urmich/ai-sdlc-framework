# Code of Conduct

Be respectful, constructive and inclusive in project issues, reviews and other
project spaces. Discuss code and behavior rather than attacking people.
Harassment, threats, discriminatory abuse, unwanted sexual attention, doxxing
and deliberate disclosure of private information are not acceptable.

Michael Urinovsky, the project's personal maintainer, moderates project spaces.
For nonsensitive conduct concerns use the
[public issue channel](https://github.com/urmich/ai-sdlc-framework/issues)
without naming private details; an existing conversation can also be flagged
using GitHub's own reporting/moderation tools where available. No confidential
project conduct mailbox is currently verified or promised. Do not post private
information while asking for a private route.

Moderation may include requesting a correction, removing content, closing a
thread or limiting participation. Decisions consider context and harm; the
maintainer may explain a decision publicly only when that does not disclose
private information. Support and response are best effort, not an employer's
HR process or a guaranteed service.

Security vulnerabilities follow [SECURITY.md](SECURITY.md), not this public route.
Contributions follow [CONTRIBUTING.md](CONTRIBUTING.md).
